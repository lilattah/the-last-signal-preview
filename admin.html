Giriş / Kurulum

YouTube'dan Bölüm İçe Aktar

Bağlantıyı yapıştır; önizlemede başlık ve kapak görüntülensin. Tam açıklama, yayın tarihi ve süre GitHub Actions üzerindeki güvenli YouTube Data API entegrasyonu tarafından alınır. API anahtarını buraya girmeyin.

İçe aktarma GitHub'da Actions → Import YouTube episode metadata → Run workflow üzerinden çalışır. Önce YOUTUBE_API_KEY adlı repository secret gerekir. İş akışı meta verileri herkese açık youtube-data.js dosyasına kaydeder; anahtarı yayımlamaz. Önizleme tek başına siteyi güncellemez.
